# 小米官网 (Xiaomi Website) - Enhanced Version

一个现代化、响应式的小米官网克隆项目，具有出色的用户体验和性能优化。

## 🎨 主要特性

### ✨ 用户体验改进

1. **平滑滚动导航**

   - 全站平滑滚动效果
   - 智能滚动位置偏移，避免被固定头部遮挡
   - 回到顶部按钮，带渐变动画效果

2. **无障碍访问 (Accessibility)**

   - 键盘导航支持 (Tab, Arrow keys, Escape)
   - ARIA 标签和语义化 HTML
   - 跳转到主内容链接 (Skip to main content)
   - 支持减少动画偏好设置

3. **响应式设计**
   - 移动端、平板和桌面端完美适配
   - 触摸手势支持 (左右滑动切换幻灯片)
   - 灵活的网格布局

### 🚀 性能优化

1. **图片优化**

   - Lazy loading (懒加载) 非关键图片
   - Intersection Observer API 实现可视区域加载
   - 图片加载错误处理
   - 关键图片预加载

2. **动画性能**

   - GPU 加速的 CSS 变换
   - 使用 `will-change` 属性优化动画
   - requestAnimationFrame 驱动的进度条动画
   - 防抖滚动事件处理

3. **代码优化**
   - CSS 变量集中管理主题颜色
   - 事件监听器使用 `passive` 标志
   - 高效的 DOM 查询和缓存

### 🎯 视觉增强

1. **现代动画效果**

   - 淡入上移动画 (Fade-in-up)
   - 悬停缩放和提升效果
   - 渐变背景和阴影
   - 进度条带发光效果

2. **交互反馈**

   - 导航链接下划线动画
   - 按钮悬停和点击状态
   - 卡片 3D 提升效果
   - 滑块导航按钮毛玻璃效果

3. **加载状态**
   - Shimmer 骨架屏动画
   - 页面加载完成指示器
   - 平滑的内容显示

### 🔧 技术特性

1. **SEO 优化**

   - 完整的 meta 标签 (description, keywords, author)
   - Open Graph 和 Twitter Card 支持
   - 语义化 HTML5 标签
   - 正确的文档结构和层次

2. **JavaScript 增强**

   - 无限循环轮播图
   - 可点击的进度指示器
   - 键盘和触摸手势控制
   - 自动播放和暂停功能

3. **CSS 现代化**
   - CSS 自定义属性 (变量)
   - Flexbox 和 Grid 布局
   - 现代动画和过渡
   - 移动优先的媒体查询

## 🎨 设计改进

### 颜色系统

```css
--mi-orange: #ff6700; /* 主品牌色 */
--mi-orange-hover: #e65c00; /* 悬停状态 */
--mi-orange-light: #ff8533; /* 浅色变体 */
```

### 阴影系统

```css
--shadow-sm: 0 2px 8px rgba(0, 0, 0, 0.1);
--shadow-md: 0 4px 16px rgba(0, 0, 0, 0.12);
--shadow-lg: 0 8px 24px rgba(0, 0, 0, 0.15);
```

### 过渡系统

```css
--transition-fast: 0.2s ease;
--transition-normal: 0.3s ease;
--transition-slow: 0.5s ease;
```
